# Physics-Informed Neural Networks for Forward and Inverse PDE Problems

**PINNs · Inverse PINNs · PyTorch · DeepXDE · Finite Differences · TVD Schemes**

A collection of computational notebooks exploring physics-informed neural networks (PINNs), inverse physics-informed neural networks (IPINNs), and classical numerical methods for the heat, Burgers', and incompressible Navier–Stokes equations. The examples connect automatic differentiation and neural-network optimization with differential-equation constraints, field reconstruction, and parameter estimation.

The repository serves as an academic learning and experimentation resource in scientific machine learning and computational physics. It contains implementations and illustrative comparisons; it is not a standardized accuracy or performance benchmark.

## Scientific scope

- **Forward modeling:** approximate solution fields from governing equations and prescribed initial and boundary conditions.
- **Inverse modeling:** jointly learn solution fields and unknown PDE coefficients from observations and physics constraints.
- **Numerical comparisons:** explore finite-difference methods (FDM) and a flux-based scheme using a minmod limiter and two-stage Runge–Kutta integration, labeled TVD in the notebooks.
- **Computational foundations:** practice PyTorch tensors, NumPy interoperability, backpropagation, and automatic differentiation.

## Mathematical formulation

The heat-equation examples investigate diffusion of a scalar field:

$$
u_t = \kappa \nabla^2 u,
$$

where $\kappa$ is the diffusivity and the Laplacian acts on one or two spatial coordinates.

The one-dimensional viscous Burgers' equation combines nonlinear transport and diffusion:

$$
u_t + u u_x = \nu u_{xx}.
$$

The inverse Burgers' notebook treats $\nu$ as a trainable parameter, using observations generated by its numerical solver with a reference viscosity of $0.02$.

For the unsteady inverse Navier–Stokes example, the residuals use:

$$
\begin{aligned}
u_t + C_1(u u_x + v u_y) + p_x - C_2(u_{xx}+u_{yy}) &= 0, \\
v_t + C_1(u v_x + v v_y) + p_y - C_2(v_{xx}+v_{yy}) &= 0, \\
u_x + v_y &= 0.
\end{aligned}
$$

Here, $u$ and $v$ are velocity components, $p$ is the pressure variable in this formulation, and $C_1,C_2$ are learned coefficients with reference values $1.0$ and $0.01$. The separate channel-flow notebook implements the steady equations with specified density and viscosity.

PINN training combines the applicable residual and observation constraints:

$$
\mathcal{L} = \mathcal{L}_{\mathrm{PDE}} + \mathcal{L}_{\mathrm{IC}} + \mathcal{L}_{\mathrm{BC}} + \mathcal{L}_{\mathrm{obs}}.
$$

The terms used depend on the notebook. Automatic differentiation evaluates neural-field derivatives; inverse experiments optimize the unknown coefficients alongside network weights. Adam is used throughout the neural examples, with L-BFGS refinement in several forward problems.

## Getting started

Clone the repository and enter its directory:

```bash
git clone https://github.com/Alikhabazian0/PINNs-IPINNs.git
cd PINNs-IPINNs
```

Use a dedicated Python environment. The main packages imported by the notebooks can be installed with:

```bash
python -m pip install numpy scipy matplotlib seaborn tqdm torch deepxde tensorflow jupyterlab ipykernel
```

Dependencies are not version-pinned, so this command is a starting point rather than a verified reproduction environment. Consult the [DeepXDE setup documentation](https://deepxde.readthedocs.io/en/stable/user/installation.html) for backend compatibility. The existing DeepXDE examples include TensorFlow-specific imports and optimizer conventions; a TensorFlow compatibility backend can be selected before starting Jupyter in Bash or Git Bash:

```bash
export DDE_BACKEND=tensorflow.compat.v1
python -m jupyterlab
```

Select the kernel belonging to your environment. Start with the tensor/backpropagation notebooks or the 2D heat PINN, then explore the Burgers' comparisons and inverse flow problem. Some PyTorch examples select CUDA automatically when it is available; device handling varies by notebook.

### Cylinder-wake data and file paths

The included `cylinder_nektar_wake.mat` contains:


If the kernel starts inside `IPINN_codes/`, use `PATH = Path.cwd().parent` instead. Update the repeated path assignments inside `load_training_data` and the training/plotting cells as well.

## Reproducibility notes

- The notebooks retain exploratory and debugging cells. For example, the DeepXDE heat notebook contains an indented diagnostic cell outside a function; the 1D Burgers' FDM notebook ends with prose in a code cell. Edit or skip these cells before sequential execution.
- The saved DeepXDE heat output includes NumPy binary-compatibility import errors. Resolve package compatibility in your chosen environment before training.
- Random sampling and initialization are not consistently seeded. Record seeds, dependency versions, device, collocation counts, and training settings when comparing runs.
- Match viscosity, boundary conditions, grids, and evaluation times before interpreting differences between numerical and neural profiles. The TVD implementations use `np.roll`, which wraps boundary indices.
- Training loss alone does not establish solution accuracy or coefficient identifiability. Quantitative studies should include independent reference errors, convergence checks, and repeated runs.
